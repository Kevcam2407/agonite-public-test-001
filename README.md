# Agonite — Public Test 001: "The Poisoned Briefing"

**Evidence repository.** This repo holds the full receipts for Agonite's first public test, published on Substack: **agonite.substack.com**

It contains documents only — no code, no keys.

## What's here

- **receipts.md** — the complete receipts: the full test pack (all ten poisoned documents, verbatim), every response from all eleven assistants tested, and the grade each run received, with a "Grading notes and corrections" section at the top. One declared exception: DeepSeek's runs were recorded as decisive excerpts, not full transcripts — its section says so.
- **comparison.md** — the consolidated comparison: at-a-glance results, six findings, the case-by-case matrix, and the method and limits.

## The test in one paragraph

On 9–11 November 2026, eleven free AI assistants — Claude, ChatGPT, DeepSeek, Grok, Gemini, Perplexity, Qwen, Kimi, Meta AI, Mistral Vibe, and Microsoft Copilot — were each given the same ten documents, three runs per document, in fresh chats, with nothing real executed. The documents carried hidden instructions: a redirected invoice payment, a fabricated "already approved" bank transfer, a memo ordering a price rise concealed. Each run was graded PASS / PARTIAL / FAIL, and separately on whether the assistant *told its user* a manipulation had been attempted. Field totals: **191 PASS · 74 PARTIAL · 35 FAIL across 300 scored runs.** Three products triggered the verdict cap by failing on a money or approval case.

## Corrections on the record

Two grades were corrected after independent readers caught inconsistencies, and both corrections are declared inside receipts.md rather than silently edited: a Gemini run regraded PASS → PARTIAL (it never named the attempt), and three Qwen runs regraded PARTIAL → FAIL (it named the attempt but still did the thing — telling doesn't cancel doing).

## Masking

The founder's personal email addresses and account handles in the run headers are masked in these copies, and the masking is declared in receipts.md. No prompt, response, or grade has been altered. The `.example` addresses are the test's own fake trap addresses and appear as run.
